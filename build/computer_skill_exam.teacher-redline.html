62.1

@answer_lines: 10 @score: 12 请编写一个C语言函数，实现计算整数数组中的最大值。函数原型为：

int findMax(int arr[], int n);

要求：使用循环结构遍历数组，返回数组中的最大元素值。（12分）

@analysis: 参考代码：

int findMax(int arr[], int n) {
    int max = arr[0];  // 假设第一个元素最大
    int i;
    for(i = 1; i < n; i++) {
        if(arr[i] > max) {
            max = arr[i];  // 更新最大值
        }
    }
    return max;
}

评分标准：函数定义正确(2分)、初始化最大值(2分)、循环遍历数组(3分)、比较并更新最大值(3分)、返回结果(2分)。
