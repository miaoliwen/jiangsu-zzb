## 57
@answer: 使用栈结构，遇到左括号入栈，遇到右括号检查栈顶匹配，最终栈空则合法。
@analysis: 参考代码如下，时间复杂度为 $O(n)$，空间复杂度为 $O(n)$。

```python
def is_valid_parentheses(s):
    pairs = {')': '(', ']': '[', '}': '{'}
    stack = []
    for ch in s:
        if ch in '([{':
            stack.append(ch)
        elif ch in pairs:
            if not stack or stack.pop() != pairs[ch]:
                return False
    return len(stack) == 0
```
