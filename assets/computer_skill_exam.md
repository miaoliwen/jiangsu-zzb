请编写一个C语言函数，实现计算整数数组中的最大值。函数原型为：
```c
int findMax(int arr[], int n);
```
要求：使用循环结构遍历数组，返回数组中的最大元素值。（12分）

@analysis: 
参考代码：
```c
int findMax(int arr[], int n) {
    int max = arr[0];  // 假设第一个元素最大
    int i;
    for(i = 1; i < n; i++) {
        if(arr[i] > max) {
            max = arr[i];  // 更新最大值
        }
    }
    return max;
}
```
