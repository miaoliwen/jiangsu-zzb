PART ONE
INTRODUCTION
A
Q · WHAT WE BUILT

一份本地跑得动的智能出卷流水线

老师或助教写一份 Markdown 试卷草稿（YAML frontmatter + 分节 + 题号 + @元数据）， 卷灵通自动解析为规范化 JSON、渲染为江苏专转本样式的 HTML， 再通过 Chrome / Edge headless 一键导出 A4 PDF。整套流程无需打开 Word，无需排版经验， 一条命令，几分钟，从草稿到可印刷成品。

B
Q · WHY NOW

专转本出卷，长期缺工具

江苏专转本计算机类每年数万人参考，但市面上几乎找不到 专门为这种固定考试样式（试卷排版、题型分节、A4 打印、公式渲染）打造的出卷工具。 Word 手画格式、公式乱码、跨页断行、红批答案叠加， 这些痛点被一线老师默默忍受了很多年。

C
Q · FORM

命令行 + 可复用的 skill

一款本地工具：Python 脚本 + PowerShell 包装 + Pandoc 渲染 + Chrome 导出。 既是给老师用的现成命令，也是给 AI Agent 复用的 skill—— 配套 schema、排版规则、workflow 文档齐全。

D
Q · INPUT

Markdown / JSON / YAML 三路输入

老师爱写的 Markdown 优先；同时支持结构化 JSON、YAML 接入已有题库系统。 解析器刻意只覆盖稳定子集，避免 anchors、aliases 等容易出错的 YAML 特性。

E
Q · OUTPUT

四套版本 一次全出

同一份题目数据，按场景切换四套 PDF：学生正式卷 / 教师卷 / 教师红批版（正确选项自动描红）/ 复习讲评版（完整元数据可见）。

// PAIN POINTS
  • 01
    Word 排版地狱
    标题区、注意事项、分节、题号、填空横线、答题卡格子—— 每一处都得手画，且换电脑/换人就格式全乱。
  • 02
    公式与代码的渲染陷阱
    MathType 公式跨平台错位、Python 代码块缩进丢失、PDF 中文乱码， 老师每次都靠"试三次导出碰运气"。
  • 03
    多版本维护成本
    同一份题，要再出学生版、教师版、红批版，Word 里复制粘贴易错位、 易漏改，临近考前一晚批量返工是常态。
  • 04
    学生自助组卷门槛高
    AI 给的题目格式各异，无法直接打印；想自己组套卷， 往往卡在"格式合规"上，而不是"题目质量"上。

PART FIVE
VARIANTS
VARIANT · 01

official
正式学生卷

隐藏答案、关键词、来源、教师备注；不出现任何红色标注。最干净的考场版本。

PREVIEW 以下属于内存储器的是（ ） A. 移动硬盘 B. U 盘 C. SRAM D. SD 卡
VARIANT · 02

teacher
教师卷

显示答案、关键词、来源、教师备注、解析；不主动描红，保持阅读舒适度。

PREVIEW 以下属于内存储器的是（ ） A. 移动硬盘 B. U 盘 C. SRAM [答案] D. SD 卡 keywords: 内存储器 · SRAM
VARIANT · 03

teacher-redline
教师红批版

教师版基础上，客观题正确选项自动描红——讲评课、组卷校对、一眼可见。

VARIANT · 04

review
复习讲评版

最完整元数据可见：答案、关键词、来源、备注、解析。用于课后复习、教研归档。
