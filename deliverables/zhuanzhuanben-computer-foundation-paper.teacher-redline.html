55.

传输速率为 72 b/s，若每个 ASCII 字符按 8 bit 计算，则 1 分钟最多可传输多少个 ASCII 字符？

答案:540
解析:

72 b/s 表示每秒传输 72 bit，1 分钟为 60 s，因此总位数为 $72 \\times 60 = 4320$ bit。1 个 ASCII 字符按 8 bit 计，则字符数为 $4320 \\div 8 = 540$。

def is_valid_parentheses(s):
    pairs = {')': '(', ']': '[', '}': '{'}
    stack = []
    for ch in s:
        if ch in '([{':
            stack.append(ch)
        elif ch in pairs:
            if not stack or stack.pop() != pairs[ch]:
                return False
    return len(stack) == 0
